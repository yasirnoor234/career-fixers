## 🌟 Overview

**Career Fixers** is a career-services platform engineered to help mid-to-senior professionals and executives pass applicant tracking system (ATS) filters and secure high-impact interviews. 

Built with **Next.js 15 (App Router)**, **TypeScript**, and a **custom Vanilla CSS Glassmorphism Design System**, the platform delivers an editorial-grade browsing experience paired with interactive review forms, live pricing calculators, and dynamic sample galleries.

---

## ✨ Key Features & Capabilities

- **100% Human-Written Methodology**: Positioned against AI-generated fluff with certified U.S.-based writing strategists.
- **ATS Semantic Architecture**: Guaranteed 95%+ parsing accuracy tested against Workday, Taleo, Greenhouse, and Lever.
- **Dynamic Interactive Resume Gallery**: Live preview modal system showcasing high-converting executive, modern, and technical resume formats.
- **Transparent Tiered Pricing**: Interactive tabbed pricing breakdowns for Entry Level ($150), Mid Career ($200), and Executive Level ($250).
- **Direct Executive Advisory**: Leadership consultation cards with direct access to Managing Partners Farah Sheikh and Suban Khalid.
- **Complimentary 3-Point Audit**: Multi-step client review intake form with local persistence and file upload simulation.
- **Complete Responsive Design**: Micro-interactions, tactile hover feedback, and fluid layouts optimized across mobile, tablet, and ultra-wide displays.
- **SEO & Structured Data**: Built-in JSON-LD `ProfessionalService` schema, open graph metadata, and canonical routing.

## 💻 Getting Started Locally

### Prerequisites

- **Node.js**: `v18.17.0` or later
- **npm** or **yarn** / **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yasirnoor234/career-fixers.git
   cd career-fixers
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the live result.

## 📦 Production Build
